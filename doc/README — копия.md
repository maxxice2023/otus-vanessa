Домашнее задание
Создание гит-репозитория проекта и доски yandex
Цель:
В результате выполнения студент развернет новый софт, необходимый для курса и дальнейших сдач ДЗ, научится создавать гит-репозиторий и изучит первичные команды работы GIT.
Реализовать доску для моделирования движения задачи по доске из статуса в статус. Каждый статус - это отдельный шаг разработки, который наполняется определенным артефактом.
Интегрировать гит-репозиторий из шага 1 с доской yandex.

Описание/Пошаговая инструкция выполнения домашнего задания:
1.	Необходимо установить GIT для версионирования кода локально + Git Extension, бесплатный клиент для работы с GIT
2.	Создать локальный репозиторий и скопировать структуру папок из проекта https://github.com/vanessa-opensource/vanessa-bootstrap
3.	Создать или проверить, что в проекте присутствую ветки master(main), develop
4.	Создать новый проект на github и загрузить туда новый проект. В дальнейшем данная структура будет использоваться для работы над ДЗ и финальным проектом
5.	Создать доску на яндекс трекере
6.	Реализовать движение задачи по доске по формату, как на вебинаре из статуса в стаус
7.	Синтегрировать доску с репозиторием на github
8.	Как связать коммиты - https://cloud.yandex.ru/docs/tracker/manager/add-repository
9.	Как настроить статусы во вложенном файле и по ссылке - https://cloud.yandex.ru/docs/tracker/manager/workflow

Критерии оценки:
Работа считается принятой, если удалось реализовать все шаги из инструкции.
